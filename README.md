# 🌾 Farmera2

Farmera2 is an AI-powered farming assistant built using Google Gemini AI.

## Features

### 🌿 Plant Disease Detection
Upload a plant image and get:
- Disease analysis
- Symptoms
- Organic treatment suggestions
- Prevention tips

### 🤖 AI Farming Assistant
Ask farming-related questions and receive AI-generated guidance.

### 🎤 Voice Assistant
Speak your question using voice input.

### 🏛 Government Schemes
Information about major farmer welfare schemes.

### 🌱 Seeds & Tutorials
Organic seeds information and farming tutorials.
